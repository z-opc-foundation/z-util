# z-util-doc-rtf

RTF 读取器，`z-util-doc` 家族成员，**零第三方依赖**（纯 JDK 字符级解析）。

## 定位
- 入口类：`com.zifang.util.doc.rtf.RtfDocReader`（实现 `DocReader` SPI）。

## 能力
- **分组栈**：每层分组独立保存字符样式，退出分组自动恢复外层状态；目的地的跳过标志不会泄漏到外层。
- **段落切分**：`\par` 结束段落，`\line` 段内换行，`\tab` 制表符。
- **字符样式**：`\b` / `\b0`、`\i` / `\i0`、`\strike`；相邻同样式片段自动合并成一个 span。
- **转义**：`\'xx` ANSI 十六进制转义、`\uN` U+ 转义（并跳过其后的替代字符）、`\\` `\{` `\}` `\_` `\-` `~`。
- **控制字分隔符**：控制字后的单个空格按 RTF 规范视为分隔符，不计入正文。
- **目的地跳过**：字体表、颜色表、样式表、信息组、图片、对象、注解、`\listtable` 等整组不产出文本。
- **表格**：`\trowd` 开始行定义、`\cell` 结束单元格、`\row` 结束行，表内段落归入当前单元格，
  连续行合成一张表格（首行作表头）。
- **列表**：`\listtext` / `\pntext` 目的地里的编号或符号作为标签注入首个 span，
  `\ilvl` 给层级，标签是项目符号时输出为无序列表。
- **图片**：`\pict` 目的地按组捕获——`pngblip/jpegblip/emfblip/wmetafile` 定类型
  （缺省按字节签名嗅探），数据支持 hex 流（`\binN` 原始字节直读）；
  `\*\picprop` 属性组跳过，`nonshppict` 回退副本去重，图片挂在正文之后。

## 能力边界
- 不还原页眉页脚、表格的合并单元格与列宽、图片与正文的锚点关系（按出现顺序输出）。
- 列表只输出 RTF 里已有的标签文本，不自己按计数器生成编号。
- 不解析 `\*\destination` 之外的复杂域（域结果按普通文本输出）。
- 编码按 ANSI（cp1252）解释，非 ASCII 的 8 位字符不做代码页切换。

## 回归语料
`src/test/java/.../RtfDocReaderTest.java` 内置 8 组真实 RTF 结构样例：段落与样式、目的地跳过、
U+ 与 ANSI 转义、制表符与格式嗅探、表格（行/单元格）、列表（标签与层级）、
图片（hex 与 \bin、picprop 跳过与 nonshppict 去重）、二进制图片直读。
