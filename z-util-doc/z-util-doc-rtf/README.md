# z-util-doc-rtf

RTF 读取器，`z-util-doc` 家族成员，**零第三方依赖**（纯 JDK 字符级解析）。

## 定位
- 入口类：`com.zifang.util.doc.rtf.RtfDocReader`（实现 `DocReader` SPI）。

## 能力
- **分组栈**：每层分组独立保存字符样式，退出分组自动恢复外层状态；目的地的跳过标志不会泄漏到外层。
- **段落切分**：`\par` 结束段落，`\line` 段内换行，`\tab` 制表符。
- **字符样式**：`\b` / `\b0`、`\i` / `\i0`、`\strike`；相邻同样式片段自动合并成一个 span。
- **转义**：`\'xx` ANSI 十六进制转义、`\uN` U+ 转义（并跳过其后的替代字符）、`\\` `\{` `\}` `\_` `\-` `~`。
- **控制字分隔符**：控制字后的单个空格按 RTF 规范视为分隔符，不计入正文。
- **目的地跳过**：字体表、颜色表、样式表、信息组、图片、对象、注解、`\listtable` 等整组不产出文本。

## 能力边界
- 不还原表格结构、列表编号、图片内容、页眉页脚。
- 不解析 `\*\destination` 之外的复杂域（域结果按普通文本输出）。
- 编码按 ANSI（cp1252）解释，非 ASCII 的 8 位字符不做代码页切换。

## 回归语料
`src/test/java/.../RtfDocReaderTest.java` 内置 4 组真实 RTF 结构样例：段落与样式、目的地跳过、
U+ 与 ANSI 转义、制表符与格式嗅探。
